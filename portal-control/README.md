# Хранилище настроек и подключений

Worker ESM с привязкой R2 `BUCKET`. Исходник: `worker/index.js`. Зависимостей npm нет. Сборка: `npm run build`, проверка артефакта: `npm run validate`. Конфигурация адаптера хостинга хранится в `.openai/hosting.json`; это формат инфраструктуры, а не часть интерфейса портала.

Публично доступно чтение общих настроек. Изменения настроек, счётчики, зашифрованные подключения, блокировки и одноразовые коды требуют серверного bearer-секрета `PORTAL_SERVICE_SECRET`.

Worker не принимает пароли, снимки оценок и профили студентов. В хранилище подключений записываются шифротекст и срок доступа. Ключ шифрования находится только в серверном окружении веб-приложения. Проверки сроков и условные записи ETag обеспечивают отзыв доступа, одноразовость кодов и блокировки. Истёкшие зашифрованные объекты могут физически оставаться до очистки.

Интеграционные тесты: `npm --prefix ../campus-vercel test`. Подробности: [SECURITY.md](../SECURITY.md).
