# AITU College

Студенческий портал: расписание 30 групп, домашние задания, книги, карта колледжа и личные оценки из College SmartNation.

**Открыть сайт:** https://aitu-college.vercel.app/

## Как самостоятельно проверить защиту данных

Ниже — инструкция для студента, который хочет понять, что происходит с его данными. Нажимайте на ссылки, открывайте файлы и находите указанные названия через поиск. Для проверки на демо-данных логин и пароль SmartNation не нужны.

### 1. Проверить шифрование соединения

Откройте сайт и нажмите на значок настроек сайта рядом с адресом. Браузер должен показывать защищённое HTTPS-соединение и действующий сертификат для домена сайта.

**Что это означает:** HTTPS шифрует передачу между браузером и сервером, защищая её от чтения и незаметного изменения по дороге. Сертификат помогает браузеру проверить, с каким доменом установлено соединение.

В инструментах разработчика → **Network** выберите основной запрос страницы и найдите в **Response Headers** заголовок `Strict-Transport-Security`. Это HSTS: сервер сообщает браузеру, что последующие подключения должны использовать HTTPS.

Откройте [серверный коннектор SmartNation](campus-vercel/lib/smartnation.server.ts), найдите `ORIGIN` и `safeURL`. Адрес начинается с `https://college.smartnation.kz`; `safeURL` проверяет домен назначения. Так можно проследить и вторую часть пути: сервер портала → SmartNation.

### 2. Посмотреть, куда передаётся пароль

Откройте два файла по порядку:

1. [Клиент подключения](campus-vercel/lib/smartnation-sync-service.ts): найдите `login` и `syncRequest`. Форма отправляет логин и пароль на `/api/smartnation` своего сайта.
2. [Обработчик входа на сервере](campus-vercel/app/api/smartnation/route.ts): найдите `brokerLogin`. Далее в [коннекторе](campus-vercel/lib/smartnation.server.ts) найдите `loginAndSync`, чтобы увидеть запрос авторизации в SmartNation.

**Что это означает:** при прямом входе сервер AITU College получает пароль для выполнения авторизации. В коде приложения пароль не записывается в базу, cookie или кеш оценок. После входа обновление работает через выданную SmartNation сессию.

Для проверки хранения найдите интерфейс `UpstreamSession` в том же коннекторе и `GradeSnapshot` в [структуре оценок](campus-vercel/lib/grades.ts): поля для сохранения пароля в них нет. Упоминание слова `password` в функции входа само по себе не означает, что пароль сохраняется — важно проследить, куда передаётся переменная.

### 3. Разобраться, как шифруются сохранённые оценки

Откройте [grade-cache.ts](campus-vercel/lib/grade-cache.ts) и найдите:

| Что искать | Что происходит |
| --- | --- |
| `generateKey` и `length:256` | Браузер создаёт ключ AES длиной 256 бит |
| `AES-GCM` | Используется шифрование с проверкой целостности |
| `getRandomValues` | Для каждой записи создаётся новое случайное значение IV |
| `saveGradeCache` | Оценки и профиль шифруются перед сохранением |
| `loadGradeCache` | Кеш расшифровывается для показа в этом браузере |
| `clearGradeCache` | При выходе удаляются кеш и ключ |

**Что это означает:** в localStorage или sessionStorage записывается зашифрованный конверт, а не открытый список оценок. AES-GCM также проверяет целостность: изменённый шифротекст не принимается при расшифровке.

Ключ хранится отдельно, в IndexedDB, как неэкспортируемый объект Web Crypto. Сам сайт использует его, чтобы показывать оценки в этом браузере. Поэтому шифрование сохранённой копии и доступ к уже открытому кабинету — разные вещи: на общем компьютере после работы нужно нажать «Выйти».

### 4. Проверить защиту серверной сессии

В [smartnation.server.ts](campus-vercel/lib/smartnation.server.ts) найдите `sessionCookie` и `readSmartNationSession`. Содержимое cookie шифруется AES-256-GCM. Для cookie подключения задаются:

- `HttpOnly` — браузер не предоставляет значение cookie обычному JavaScript страницы;
- `Secure` — в production cookie передаётся по HTTPS;
- `SameSite=Strict` — ограничивает отправку cookie при запросах с других сайтов.

В [smartnation-broker.server.ts](campus-vercel/lib/smartnation-broker.server.ts) найдите `seal`, `open` и `device`. Общая сессия SmartNation сохраняется на серверной стороне в зашифрованном виде, а браузер получает ссылку на своё подключение внутри защищённого cookie. Сервер расшифровывает подключение, когда запрашивает свежие оценки.

Ключ берётся из серверной переменной `SMARTNATION_SESSION_SECRET`. Рабочее значение не включено в GitHub и клиентский JavaScript. Открытый исходный код позволяет изучить алгоритм, но не раскрывает рабочий ключ.

### 5. Проверить, как разделён доступ

Откройте [парсер личного журнала](campus-vercel/lib/smartnation.server.ts) и найдите `parseJournalPayload`: он требует `isStudent === true` и ровно одну запись студента в личном ответе. При неоднозначном ответе чтение отклоняется.

В [API SmartNation](campus-vercel/app/api/smartnation/route.ts) найдите `sameOrigin`. Вход, обновление и выход проверяют источник запроса. В [хранилище подключений](campus-vercel/lib/smartnation-broker.server.ts) функции `validate` и `locked` проверяют доступ устройства к своему подключению и управляют обновлением общей сессии.

**Что это означает:** личные оценки не становятся публичным разделом расписания. Их чтение связано с авторизованным подключением; произвольного параметра «покажи оценки другого студента» в API портала нет.

Для других разделов тоже можно проверить права по коду:

| Механизм | Файл |
| --- | --- |
| Вход администратора и проверка его сессии | [portal.server.ts](campus-vercel/lib/portal.server.ts) |
| Доступ старосты к своей группе | [moderator.ts](campus-web/lib/moderator.ts) |
| Проверка прав на просмотр вложения к ДЗ | [attachments/[id]/route.ts](campus-web/app/api/attachments/%5Bid%5D/route.ts) |

### 6. Повторить простую проверку в браузере

На компьютере откройте сайт **в новом приватном окне** и выберите «Оценки» → **«Демо-режим»**. Это позволяет проверить кеш без настоящего аккаунта и без замены оценок в вашем обычном окне.

1. Откройте инструменты разработчика: `F12` или пункт меню браузера «Инструменты разработчика».
2. Перейдите в **Application** → **Local Storage / Session Storage**. Найдите `aitu-grades-v2`: внутри должны быть поля `v`, `iv`, `data`, а не читаемый список предметов и оценок.
3. В **IndexedDB** найдите `aitu-private-cache` → `keys`: здесь находится отдельный объект ключа `current`.
4. Нажмите на сайте **«Выйти»** и обновите отображение хранилищ в DevTools. Запись кеша и запись ключа должны исчезнуть. Сама пустая база IndexedDB может остаться.

Демо не создаёт реальную сессию SmartNation. Флаги cookie подключения можно изучить в коде из шага 4 без ввода своего пароля.

Не публикуйте значения cookie, коды входа или полные сетевые запросы своего реального аккаунта. Для обсуждения проверки достаточно названий файлов и результата на демо-данных.

### 7. Проверить импорт без передачи файла на сервер

В [smartnation-sync-service.ts](campus-vercel/lib/smartnation-sync-service.ts) найдите `parseFile`: файл читается через `file.arrayBuffer()` или `readXlsxFile(file)` и разбирается в браузере. В этой функции нет запроса загрузки содержимого файла на сервер.

Это можно повторить с тестовым CSV/JSON/XLSX: откройте **Network**, импортируйте вымышленные оценки и проверьте, что запрос отправки содержимого файла не появился. Сохранённый результат использует тот же зашифрованный кеш из шага 3.

## Для тех, кто хочет запустить тесты

После клонирования репозитория, с установленными Node.js 22 и Python 3:

```sh
python3 scripts/check-source.py
npm --prefix campus-vercel ci
npm --prefix campus-vercel test
npm --prefix campus-vercel run build
```

Тесты используют вымышленные данные. Они проверяют шифрование кеша и сессий, отказ при подмене шифротекста, удаление кеша при выходе, разделение аккаунтов и одноразовые коды устройств. Полный набор включает соседний каталог `portal-control`.

Проверяйте конкретные механизмы и версию кода. Для технической оценки доступны [правила доступа и границы защиты](SECURITY.md), [результаты аудита](docs/security-verification-2026-10-20.md) и [запуски GitHub Actions](https://github.com/Xsteel2121/aitu-college-portal/actions). Эти материалы дополняют инструкцию и позволяют оценить состояние всей системы.

## Где находится реализация

- `campus-vercel/` — основной сайт и серверное подключение к SmartNation;
- `portal-control/` — настройки и зашифрованное хранилище подключений;
- `campus-web/` — общие ДЗ, модерация, файлы и Web Push.

Локальный запуск интерфейса: `npm --prefix campus-vercel run dev` после установки зависимостей. Серверные переменные перечислены в [.env.example](campus-vercel/.env.example). Для своего развёртывания нужны собственные настройки сервисов и секреты.

Дополнительно: [объяснение HTTPS от MDN](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Transport_Layer_Security) и [Web Crypto / AES-GCM](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt).
