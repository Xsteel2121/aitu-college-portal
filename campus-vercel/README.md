# AITU College — веб-приложение

Текущий интерфейс портала на Next.js, React и TypeScript.

Запуск из этого каталога: `npm ci`, `npm run dev`. Для production: `npm run build`, `npm start`. Секреты заполняются по `.env.example` через локальный игнорируемый `.env.local` или окружение хостинга.

Полная архитектура, сценарии проверки и политика обработки данных описаны в [корневом README](../README.md) и [SECURITY.md](../SECURITY.md).

`npm test` запускает проверки импорта и расчётов, шифрования кеша, сессий, администратора и подключения нескольких устройств. Для интеграции с хранилищем должен присутствовать соседний каталог `portal-control`.

Данные расписаний находятся в `lib/timetable.json`, календарь — в `lib/academic-calendar.json`. Исходные предоставленные документы доступны в `public/sources`. Каталог книг хранит ссылки на источник; PDF-файлы учебников не включены.
