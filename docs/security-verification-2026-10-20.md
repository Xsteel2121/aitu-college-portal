## Что требуется исправить

Сервис ДЗ использует старые версии инструментов и фреймворка, включая `next` 16.3.4. В его диапазон попадает [GHSA-vcvr-r3jv-pc5j](https://github.com/advisories/GHSA-vcvr-r3jv-pc5j), критическая проблема Node.js `ImageResponse` при передаче недоверенных значений в SVG. Advisory указывает исправление в 16.3.6; другие предупреждения в отчёте требуют более новых исправлений. Это предупреждение по зависимости, а не подтверждение наличия у данного сервиса уязвимого маршрута.

Порядок устранения: обновить совместимые версии фреймворка и инструментов, пересобрать Worker, повторить проверку API ДЗ, модерации и файлов, затем развернуть проверенный артефакт и снова запустить аудит. Не следует применять `npm audit fix --force` без проверки совместимости. Точные затронутые диапазоны и доступные версии исправлений сохранены в JSON-отчёте.

Зависимости сервиса ДЗ и работающий production не обновлялись в рамках подготовки публичного репозитория. Зелёная проверка основного приложения не отменяет красную проверку сервиса ДЗ. Workflow публикует их отдельными заданиями и не скрывает неуспешный результат.

## Что не доказывает этот отчёт

Отсутствие известных уязвимостей в одном дереве npm не означает полной безопасности. Шифрование, Origin, cookie и ограничения ролей проверены в перечисленных фикстурах; конфигурацию боевой инфраструктуры, права администраторов, неизвестные уязвимости и поведение всех внешних сервисов эти проверки не подтверждают.
